the opx edge

Fixes you won't find anywhere else.

📶

Xiaomi / MIUI USB — solved

MIUI kernels misreport full-speed USB adapters as low-speed, killing Realtek dongles. OPX-Demon ships a custom 6.12.94 kernel with a hub.c classification fix plus a QEMU host-libusb quirk. Your rtl8188fu finally enumerates.

EXCLUSIVE
🔧

Drivers pre-built in

rtl8xxxu, rtw88 (8821cu/8822bu/8812au), ath9k_htc, carl9170, mt76, rt2x00, rtl8187, zd1211rw — compiled into the kernel. Adapter firmware ships inside the rootfs, so it just works after install.

⚡

Rootless QEMU engine

No root? No problem. The same Debian rootfs boots in a QEMU VM at localhost:1050 on stock devices — with resumable downloads, fixed libslirp boot and no more stuck login prompts.

Requirements.

📱

Android device

Android 7.0 (API 24) or newer. Root via Magisk/KernelSU for the native chroot engine; the rootless QEMU engine runs on stock devices.

💾

~1 GB free storage

For the Debian trixie chroot, bundled tools and firmware signatures.

📶

USB Wi-Fi adapter

External monitor-mode adapter for WiFi attacks — Atheros AR9271 or Realtek 88XXAU recommended. OTG cable required.

🧮

Gadget-capable kernel (optional)

For HID Attacks & USB Arsenal: USB configfs enabled, kernel ≥ 3.19, populated /sys/class/udc/. Most modern kernels qualify.

answers

Frequently asked questions.

Is OPX-Demon really free?
Yes — 100% free and open-source under GNU GPL v3.0. No ads, no subscriptions, no premium tiers. The source lives at github.com/OPX-Aminul/OPX-Demon.
Does it need a rooted phone?
Root unlocks the fast native chroot engine, but a stock, non-rooted device can still run the built-in rootless QEMU VM — the same Debian rootfs booted at localhost:1050.
Which USB Wi-Fi adapters are supported?
Monitor-mode adapters like the Atheros AR9271 and Realtek 88XXAU family. Drivers rtl8xxxu, rtw88, ath9k_htc, carl9170, mt76, rt2x00, rtl8187 and zd1211rw are pre-built into the shipped kernel, with firmware bundled in the rootfs.
Why does it work on Xiaomi / MIUI when the original app doesn't?
Xiaomi kernels misreport full-speed USB devices as low-speed, so Realtek adapters abort enumeration. OPX-Demon ships a custom 6.12.94 kernel with a hub.c classification fix plus a QEMU host-libusb quirk — two independent layers that make adapters like rtl8188fu enumerate correctly.
Is this legal?
OPX-Demon is a security-testing tool built for authorized testing, education and research only. You are responsible for complying with all applicable laws and for obtaining explicit permission before testing any system or device you do not own.
How do I get the latest version?
Use any Download button on this site — it always points at the newest release asset on GitHub Releases. The in-app OTA core manager keeps the chroot, QEMU kernel and tools up to date separately.
